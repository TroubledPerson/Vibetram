# Vibetram

Independent hobby project designed for Codex and ChatGPT integration. Compatibility is under development.

## Planned editions

- **Vibetram Mobile**: Android development is underway.
- **Vibetram Desktop**: a planned Electron-free desktop client, intended to reduce overhead and RAM usage. This is a design goal, not a measured performance claim or an existing desktop release.

## Current status

This repository is an initial project placeholder. Source publication is pending completion of source, licence, notices and privacy review.

The first planned public Android test build is **Vibetram Alpha 1.91**, with the intended release asset name `Vibetram-Alpha-1.91-Android.apk`. It has not yet been built or uploaded here. Version 1.90 will not be published as a substitute. Offline host checks do not establish live pairing compatibility or phone-test completion.
